Engineering & Research Log

Click any node to expand verified telemetry

  • Built catbench (uv run catbench run): 25 queries (19 test, 6 dev), 6 multi-step workflows, ~1,990 graded pairs across 269 catalog listings with 95% bootstrap CIs.
  • Test split proved text-embedding-3-small beats BM25 across all metrics (R@10 0.801 vs 0.651, nDCG@10 0.776 vs 0.631, paired Δ +0.145, MRR 0.921 vs 0.733).
  • Benchmarked 55 configurations (4 embedding models + BM25 hybrid; 243 tests; CEO reproduced all 55 runs) and proposed a one-line provider-pinning fix for hosting latency variance.
  • Built TILE (C++ / AVX2 SIMD): stores compressed 2-byte tile borders and recomputes only optimal-path tiles, cutting traceback memory from O(mn) to O(mn/T + T²).
  • D63 benchmark (Xeon Silver 4216, 1 core): exact score agreement across all 2,472 pairs (ONT 1k–500k, SARS-CoV-2, PREFAB-R, BAliBASE 3); beats Myers–Miller by up to 25.4× on ONT-500k (68.0 s vs 1,728 s; 7.0× faster on 8 threads).
  • Latest D71 (Steps 14–18): dna_twilight_like runs 22–23× faster than Myers–Miller (up from 5×); porting to CUDA for TWILIGHT.
  • Built automated Python pipelines validating HL7/FHIR R4 clinical schemas (DiagnosticReport, Patient) and pytest/Pydantic mocks stress-testing EHR APIs.
  • Built evaluation harnesses benchmarking clinical LLM responses on hallucination rate, latency, and semantic similarity across prompts, plus embedding retrieval recall analysis.

Authored computational software engineering evaluation tasks; 3 tasks accepted after expert peer review.
